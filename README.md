# Requi-Feed

This is a web application for managing requirements and feedback. The backend is built with NestJS and the frontend is built with React.

## Installation

### Backend

1. Navigate to the `requi-feed_backend` directory:
   ```bash
   cd requi-feed_backend
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run start:dev
   ```

### Frontend

1. Navigate to the `requi-feed_frontend` directory:
   ```bash
   cd requi-feed_frontend
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
